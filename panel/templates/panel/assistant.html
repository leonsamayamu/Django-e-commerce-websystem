Strict safety design

  • No database access. The AI code cannot import models or query data, and has no tools. It sees only the commands you write below and the visitor's question.
  • It never receives orders, customers, stock, prices or staff data. Anything not written in a command, it does not know.
  • Built-in rules (placed last, so they win) forbid revealing instructions, asking for passwords or PINs, or taking actions.
  • Rate limits per visitor, 500-character questions, short replies, and plain-text output only.
