How to set up

  1. In your PayHero dashboard create a payment channel and note its Channel ID.
  2. Create API keys (username and password) under Account.
  3. Click Add gateway and paste them here. They are encrypted and never shown again.
  4. Make sure the shop is reachable at a public https address and set PUBLIC_BASE_URL, so PayHero can send payment confirmations.

Safety

  • Orders are marked paid only after the shop confirms the payment with PayHero directly, never from the callback alone.
  • Amounts are re-checked against the order total.
  • {% if public_url_set %}Public URL is configured.{% else %}PUBLIC_BASE_URL is not set. Customers' payments still complete (the checkout page confirms them), but PayHero's own callbacks cannot reach a local computer.{% endif %}
